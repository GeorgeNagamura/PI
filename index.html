Definição - O que é o Bot QUINTA SÉRIE?

Que $%#@ é essa?

Quinta Série é um Bot de Telegram para jogar Cartas Contra Humanidade online com os amigos.

Cartas Contra Humanidade é um jogo de cartas (duh) em que um jogador recebe uma carta com uma frase incompleta. Ex: Minha comida favorita é ____. Os outros jogadores usam outras cartas, com frases curtas para sugerir algo que complete a frase. Exemplos de cartas: "Sua mãe", "Uma cueca freada" etc.

As sugestões não precisam fazer sentido, nem estarem sintaticamente corretas, basta fazer os outros rirem. Depois que todos os jogadores fizerem sua sugestão, todos votam para escolher a sugestão mais engraçada.
